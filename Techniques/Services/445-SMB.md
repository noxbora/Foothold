# 445 — SMB

Server Message Block: Windows file and printer sharing, and the protocol most lateral movement rides on. Reach for this note the moment 445 (or 139) shows up. It is worth the most of any port on a Windows box, because a share plus a credential is often the whole engagement.

## List the shares with no credential

```bash
smbclient -L //<ip> -N
```

- `-L` → list the shares rather than connecting to one.
- `-N` → no password, the null session. Drop it and `smbclient` prompts for a password and your no-credential probe becomes a hung login instead of the answer you wanted.

## Connect to a share

```bash
smbclient //<ip>/<share> -N
```

- swap `-N` for `-U '<domain>\<user>%<pass>'` once you hold a credential. The inline `%pass` form skips the interactive prompt, which matters when you are scripting the same connection across several shares.

Inside the prompt, `get`, `put`, and `mget *` move files. To pull a whole tree at once:

```text
recurse ON
prompt OFF
mget *
```

- `recurse ON` → without it `mget *` takes only the current directory and a deep share comes back looking nearly empty.
- `prompt OFF` → without it every file waits for a `y`, which on a large share reads as a hang.

## Which of those shares you can actually read

```bash
smbmap -H <ip>
```

- no credential flags at all → a nameless session is this tool's default when no user is given, so the command above is the anonymous probe. Add `-u '<user>' -p '<password>'` (and `-d <domain>` for a domain account) and the same command becomes the fastest way to learn what a credential you just found is actually worth.
- the column that matters is permissions: `READ`, `READ, WRITE` or `NO ACCESS` per share. That is the difference between this and the share listing above, which proves a share exists and nothing more.
- `-r <share>` walks the contents of one share once you know it opens, and `--depth <n>` bounds how far down it goes. Start shallow: a share with a deep tree turns a two-second answer into a long one.

> [!important] The permissions column is a test the tool ran, not a field the server published
> It works out `WRITE` by creating a directory on the share and then removing it, falling back to creating and removing a file. So this command is not a read-only probe: on every share you can write to, it leaves a create and a delete behind in the file system and in whatever auditing is watching that share. Know that before you fire it at a production file server, and know it when you are asked afterwards what you touched.

## Reach the administrative shares

<!-- dup-ok -->
```bash
smbclient \\\\<ip>\\ADMIN$ -U Administrator
```

- `\\\\` → a [[Security-Terms#^unc|UNC path]] with each backslash escaped for bash; four backslashes render as the two the client needs.
- `ADMIN$` → the hidden share mapped to `C:\Windows`. Writable `ADMIN$` means code execution via [[Security-Terms#^psexec|PsExec]] — that is the lateral-movement route, not just file access.
- `-U Administrator` → the account to authenticate as; add `%<pass>` or `-U '<domain>\<user>'` for a domain account.

## Enumerate before authenticating

```bash
nmap --script smb-enum-shares,smb-os-discovery,smb-security-mode -p445 <ip>
```

```bash
enum4linux-ng -A <ip> -oA results
```

- `smb-os-discovery` → OS build and hostname with no credential, straight into [[Public-Exploit-Workflow]] if the build is old.
- `-A` → every check the tool has, over a null session, in one sweep: users, groups, shares, the password policy, the identifier walk and the OS details. The user list it prints is the input to a spray, and the policy it prints is what tells you how fast you may run one.
- `-oA results` → writes the same findings out as structured files you can grep an hour later, one file per format. Give it a name with an extension already on it and you get `results.txt.json`, which is harmless and looks like a bug.
- the older `enum4linux` is still on most distributions and is a shell wrapper around the same underlying tools; the rewrite above adds the parsing. When a command in a write-up uses `-a` rather than `-A`, that is which one it means.
