# 3389 — RDP

Remote Desktop Protocol: an interactive Windows desktop over the network. Reach for this note when 3389 is open and you hold a Windows credential — but treat the graphical session as a last resort for *looking* at something, not as the place you do your work.

## Connect

```bash
xfreerdp /u:user /p:pass /v:<ip>:3389 /cert:ignore /dynamic-resolution +clipboard
```

- `/u:` `/p:` `/v:` → username, password, and target host:port.
- `/cert:ignore` → skip certificate validation. Without it the self-signed cert every lab RDP host presents aborts the connection with a certificate error that looks like a refusal.
- `/dynamic-resolution` → resize the remote desktop to your window instead of a fixed small box.
- `+clipboard` → share the clipboard both ways. Not a convenience — the reason is in the next section, and connecting without it will cost you time on any non-US keyboard.

> [!important] Wrap the password in single quotes
> `/p:'P@ssw0rd!'` — your own shell reads the string before `xfreerdp` ever sees it, and in interactive bash a `!` is a history expansion, `$` starts a variable and a backtick starts a command. Double quotes stop `$` and backticks but **not** `!`; single quotes stop all three. Get it wrong and bash either errors with `event not found` or silently sends a different password, which comes back as `ERRCONNECT_LOGON_FAILURE` and reads as a wrong credential rather than a quoting mistake.

## Working inside the session

**Always connect with `+clipboard`.** The remote desktop hands your keystrokes to the target's keyboard *layout*, not yours, so `\`, `|`, `{`, `"` and `'` land somewhere else on any non-US layout. Do not fight it: type the command in your own terminal, copy it, paste into the session with `Ctrl+V`. It works in the other direction too — copy a hash or a flag out instead of transcribing it by eye.

**Then stop working in the GUI.** RDP is for *looking* at the desktop — a running application, a dialog, something only the interactive session shows. Everything else is better done from a shell on your own machine: get one out with [[Shells]] — or, when the box has WinRM open and you already hold the credential, skip both and use [[5985-WinRM]]. Either way you keep your keyboard, your scrollback, `grep`, `tee`, and a copy of every command. A `cmd.exe` window inside an RDP frame gives you none of that.
